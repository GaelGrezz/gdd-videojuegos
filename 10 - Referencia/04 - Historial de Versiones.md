# Historial de Versiones

## Descripción de la sección

Registra los cambios importantes realizados al GDD. Esto permite conocer cómo evolucionó el diseño y cuándo se modificó una decisión.

## Formato

| Versión | Fecha | Cambios principales | Responsable |
|---|---|---|---|
| 0.1.0 | | Creación del documento | |
| 0.2.0 | 2026-10-20 | Unificación de reglas y nombres entre secciones; linterna siempre encendida; tienda y moneda fuera del prototipo; plataforma PC con teclado y mouse | |
| 0.2.1 | 2026-10-27 | Estado del prototipo de Unity en la ficha, los sistemas, el roadmap y el backlog; tecla de recarga; ilustraciones de Nicolás e Issac | |
| 0.3.0 | 2026-10-28 | Interfaz diseñada en Figma: se llenan UI y Menús e Interfaz Visual con el menú principal, el HUD, la selección de mejora y la pausa; se documentan el motor y las herramientas | |
| 0.3.1 | 2026-10-28 | Nueva ilustración de Eco-10; se quitan las referencias visuales anteriores del soldado y de Issac | |

## Convención sugerida

- **MAJOR:** cambios estructurales importantes.
- **MINOR:** nuevas secciones o características relevantes.
- **PATCH:** correcciones, aclaraciones y pequeños ajustes.

> [!example] Ejemplo
> `1.2.3` → versión mayor 1, versión menor 2, corrección 3.
